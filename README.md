## 📌 Sobre o Projeto

A **Barbearia Estilo** é uma landing page criada para representar uma barbearia moderna e profissional.

O objetivo foi construir um site visualmente atraente, rápido e totalmente responsivo, simulando um projeto real para negócio local.

## ✨ Funcionalidades

- ✅ Navbar fixa com botão **Agendar Agora**
- ✅ Hero section com imagem de destaque
- ✅ Serviços com preços em cards
- ✅ Galeria de fotos
- ✅ Depoimentos de clientes
- ✅ Formulário de agendamento
- ✅ Localização com mapa
- ✅ Botão flutuante do WhatsApp
- ✅ Layout 100% responsivo (mobile, tablet e desktop)
